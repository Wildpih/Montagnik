TranscribeStudio
================

СТРУКТУРА ПАПКИ
===============
TranscribeStudio/
 ├── START.bat              <- ЗАПУСК программы
 ├── START_DEBUG.bat        <- запуск с выводом ошибок
 ├── setup.bat              <- ПЕРВЫЙ ЗАПУСК — установка
 ├── setup.ps1
 ├── uninstall.bat
 ├── uninstall.ps1
 ├── DOWNLOAD_MODELS.bat    <- консольный менеджер моделей
 ├── download_models.py
 ├── app.py                 <- бэкенд (не трогать)
 ├── main.py                <- запуск окна (не трогать)
 ├── requirements.txt
 ├── ИНСТРУКЦИЯ.txt
 └── templates/
      └── index.html        <- интерфейс (не трогать)

 Создаются автоматически:
 ├── python/    <- Python (~1.5 ГБ, создаёт setup.bat)
 ├── ffmpeg/    <- FFmpeg (~90 МБ, создаёт setup.bat)
 ├── models/    <- языковые модели (от 460 МБ до 3.1 ГБ)
 ├── projects/  <- ваши проекты
 ├── uploads/   <- аудио и видео файлы
 └── exports/   <- экспортированные файлы


ПЕРВЫЙ ЗАПУСК (один раз)
========================
1. Запустите setup.bat
   Установит Python, FFmpeg и все зависимости (~1.5 ГБ)
   Время: 15-40 минут. Нужен интернет.

2. Запустите START.bat — откроется одно окно с тремя вкладками.

3. Перейдите во вкладку «Модели» и скачайте модель.
   Для перевода дополнительно скачайте NLLB-200.


ВКЛАДКИ В ПРИЛОЖЕНИИ
====================
Три вкладки в верхней части окна:

  [🎙 Транскрипция]
    - Создайте проект (кнопка «＋ Новый проект» в левой панели)
    - Загрузите аудио или видео
    - Выберите модель и язык, нажмите «Распознать»
    - Редактируйте реплики: двойной клик по тексту
    - Экспорт: CSV, SRT, JSON, DOCX, архив проекта (.tsproject)

  [🌐 Переводчик]
    - Требует скачанной модели NLLB-200 (вкладка «Модели»)
    - Выберите язык оригинала и язык перевода
    - Нажмите «Перевести» — перевод появится рядом с оригиналом
    - Кнопка «Очистить» удаляет перевод из проекта
    - Экспорт: CSV, SRT, JSON, DOCX с колонкой перевода

  [📦 Модели]
    - Список всех доступных моделей с размерами
    - Кнопка «Скачать» / «Удалить»
    - Поиск по названию или языку
    - Прогресс скачивания отображается в реальном времени


ФОРМАТЫ ФАЙЛОВ
==============

ДИАГНОСТИКА
===========
Если START.bat не открывает окно:
  1. Запустите START_DEBUG.bat — покажет текст ошибки
  2. Проверьте файл start_error.log рядом с app.py

Если «No module named»:
  Запустите setup.bat ещё раз

Если «Port 5000 is already in use»:
  Программа уже запущена. Закройте окно и попробуйте снова.

Если «FFmpeg не найден»:
  Запустите setup.bat — скачает ffmpeg автоматически.

Диагностика (пока программа запущена):
  http://127.0.0.1:5000/api/debug
